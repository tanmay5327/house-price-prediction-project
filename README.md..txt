# House Price Prediction Model

This project is part of my data analytics internship assignment. It uses a machine learning regression approach to predict house prices based on key property features.

## Files Included
* Code file with data cleaning, EDA, and model training
* Requirements text file with library dependencies
* Dataset analysis structure

## Technologies Used
* Python
* Pandas & NumPy
* Scikit-Learn
* Matplotlib & Seaborn

## How to Run
1. Download the project folder.
2. Install dependencies using your terminal:
   pip install -r requirements.txt
3. Run the python script or notebook to view model outputs.
